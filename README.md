# AI Tutoring Framework

A research framework website for teaching precalculus with responsibly integrated AI tutoring at NYU Abu Dhabi. Built with Next.js and TypeScript.

## Overview

This project presents a six-phase daily learning cycle that seamlessly integrates AI tutoring with classroom instruction for precalculus education.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Radix UI components

## Getting Started

```bash
pnpm install
pnpm dev
```
